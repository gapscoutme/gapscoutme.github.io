GapScout Privacy Policy

Effective 20 October 2026

GapScout is a private market-research application with a single user: the person who operates it ("the operator"). This policy explains what data GapScout handles and how, including data obtained through Google services. Questions go to the contact address in section 6.

1. This website

This site is informational. It sets no cookies, runs no analytics, and collects no personal information. It is hosted on GitHub Pages, whose servers may record standard web-server logs (such as IP addresses) under GitHub's privacy statement.

2. The GapScout application

The application runs on the operator's own computer. It has no user accounts, no sign-up, and no public access. It does not collect, store, or process personal information about members of the public. The data it works with are published statistics from government and other public sources.

3. Google user data

GapScout connects to the Google Ads API using OAuth authorization granted by the operator for the operator's own Google Ads account.

  • What is accessed. Keyword Planner data only: search-volume estimates and cost-per-click estimates for keywords the operator enters. The application does not read campaign performance, billing, or audience data, and it never creates, edits, enables, or pauses advertising campaigns.
  • How it is used. The data is used solely to estimate paid-search demand and acquisition cost inside the operator's own market analyses. It is not used for advertising, profiling, or any other purpose.
  • Where it is stored. Fetched values are stored in a local database on the operator's computer, together with the date retrieved and the source, so that each estimate can be traced. OAuth tokens are stored locally and used only to make these requests.
  • Sharing. Google user data is not shared with, sold to, or transferred to any third party. It is not used to train or improve machine-learning models.
  • Retention and deletion. Fetched values are kept until the operator deletes them or refreshes them with newer data. Access can be revoked at any time at myaccount.google.com/permissions, after which the application can no longer make requests.

GapScout's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

4. Other data sources

All other data the application fetches comes from public, official datasets (for example United States Census, Bureau of Labor Statistics, and state licensing records). Each source's terms of use are recorded in the application and respected; sources whose terms do not permit automated access are read by hand and cited by page.

5. Changes

If this policy changes, the new version will be posted at this address with a new effective date.
